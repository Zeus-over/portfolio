## Lancer le site en local

1. Télécharge ou clone le dépôt :
   ```bash
   git clone https://github.com/Zeus-over/portfolio.git
   ```
2. Ouvre le dossier `portfolio`.
3. Double-clique sur `index.html` pour l'ouvrir dans ton navigateur.

## Personnalisation

- **Textes** : modifie le contenu dans `index.html`.
- **Couleurs** : change les variables en haut de `joseph.css` (`--accent`, `--bg`, `--card`…).
- **Numéro WhatsApp** : modifie la constante `WHATSAPP_NUMBER` dans le script de `index.html`.
- **Certificats** : ajoute une carte `certificate-card` dans la section `#certificates`.
